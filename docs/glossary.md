# Zumba 歌單管理系統專有名詞定義 (Glossary)

本文件定義本專案開發中使用的核心名詞與其商業邏輯定義，以確保開發與架構共識。

---

## 核心名詞

### 1. Live 歌單 (Live Playlist)
- **定義**：某位 Zumba 老師目前在實際課堂上使用中的歌曲列表。
- **商業規則**：
  - 每個使用者的 Live 歌單是獨立隔離的。
  - Live 歌單可以隨時透過 Bot 發送 `/update_live` 來更新。
  - 更新時會與當前 Active 歌單比對，多出來的為「新增」，少掉的為「移除」，不變的保留。
  - Live 歌單有播放順序；文字輸入的行序就是更新後的播放順序。
  - 順序具有業務意義，例如暖身通常位於前段、收操通常位於後段。
  - 只調整歌曲位置時不建立新的使用歷史，也不結束原有使用區間。

### 2. 使用歷史 (Live History)
- **定義**：一首歌被某個使用者啟用與停用在 Live 歌單中的歷史區間紀錄。
- **商業規則**：
  - 同一首歌可以有多次使用紀錄（例如：6/15-6/17 使用，7/15-7/18 再次使用）。
  - 每次新增會建立一筆 `start_date` 為當天、`end_date` 為空的紀錄。
  - 每次移除會將該筆紀錄的 `end_date` 更新為當天。

### 3. ZIN 教材 (ZIN Albums)
- **定義**：Zumba 官方（Zumba Instructor Network）每月發行給會員老師的音樂教材與編舞專輯。
- **商業規則**：
  - 每一期教材（如 `Zin123`）的歌單內容在資料庫中是全系統共用的，不需要每個使用者獨立匯入。
  - 使用者可以查詢特定 ZIN 教材中，有哪些歌是自己「已使用過」（有 Live 歷史紀錄）、「未使用過」以及其使用時間。

### 3.1 Mega Mix 教材 (MM Albums)

- **定義**：與 ZIN 並列的每月 Zumba 音樂教材類型，系統內簡稱 `MM`。
- **商業規則**：
  - MM 與 ZIN 使用相同的通用教材模型。
  - 目前教材以「類型＋期數」唯一識別；發行月份可以留空，之後補上。
  - MM 教材由管理員維護，全系統共用；老師只能查詢自己對其中歌曲的使用狀況。

### 4. 歌名標準化 (Song Name Normalization)
- **定義**：將輸入的原始歌曲名稱進行字串清理以供比對的程序。
- **規則**：
  - 清除字首字尾的空白字元。
  - 清除首尾各種全半角引號（如 `"`, `“`, `”`, `'`, `‘`, `’`）。
  - 轉為小寫字元比對。

### 5. 模糊比對 (Fuzzy Matching)
- **定義**：當使用者輸入歌名與資料庫既有歌名有微小差異時，系統透過演算法判定是否為同一首歌的機制。
- **規則**：
  - 使用 **Levenshtein 編輯距離演算法** 計算相似度。
  - 相似度大於等於 **95%** 時，自動視為同一首歌曲。
